================================================================================
MIDDLEWARE & AUTHENTICATION
================================================================================

Routes yang require Authentication (middleware 'auth'):
- /dashboard
- /profile (edit, update, destroy)
- /files/* (download files)
- /notifications/* (notification routes)
- /employee/* (semua employee routes)
- /hr/* (semua hr routes - dengan role:hr,leader)
- /leader/* (semua leader routes - dengan role:leader)

Role-based Access Control:
├── employee - Hanya karyawan
├── hr - HR dan Leader
└── leader - Leader/Direktur

================================================================================
CATATAN PENTING UNTUK INTEGRASI
================================================================================

1. Authentication menggunakan Fortify (Laravel)
   - All auth routes di: routes/auth.php

2. Role-based access control menggunakan middleware
   - Middleware: 'role:employee', 'role:hr,leader', 'role:leader'

3. Export functionality mendukung: XLSX dan PDF
   - Menggunakan ExportController pattern

4. Face Recognition Integration:
   - FaceEnrollment (Employee) - Self enrollment
   - FaceRegistration (HR) - Admin registration
   - Public face-api folder untuk face detection/recognition

5. File Download Security:
   - Semua file download melalui FileDownloadController
   - Support untuk: absence proofs, work report files

6. Notification System:
   - Mark as read functionality
   - Inbox view untuk semua notifikasi

7. Soft Delete Support:
   - Employee controller support restore dari soft deleted records
